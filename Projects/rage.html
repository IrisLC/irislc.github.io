Rage Game, Spring 2024

Unreal Engine

The final project for an intro Game Development class, tasked with creating a 3d platformer. I Set out to make a rage game that achieves this effect via traps that the player cannot see coming (in the vein of 2d games like "I want to be the guy" and "Cat Mario") and using player's expectations against them. The visual presentation of the game is very rough, but that was to put more time into figuring out ways to play with what the player expects to happen, and then do the opposite of it in order to get them to give an appropriate reaction. Playtest feedback showed that players fell for most, if not all of the attempts, and despite the frustration, found the experience very fun (laughter accompanied most of the deaths). First real experience with using Unreal Engine 5 Blueprints.
